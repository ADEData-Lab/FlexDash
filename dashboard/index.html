Understanding Turn-Up vs Turn-Down

When Time-of-Use tariffs are included, turn-up capacity appears higher because customers shift load into off-peak periods. This reflects demand flexibility, not new generation. Managed assets are predominantly turn-down (demand reduction).

Turn-Up vs Turn-Down

Turn-up dominated by ToU load shifting; turn-down by managed DSR.

Explicit vs Implicit Flexibility

Explicit = contracted, Implicit = price-responsive behavior.

Latent Potential Methodology

Latent potential estimates the total GB flexibility if all eligible assets were actively managed. Calculated as: Average flex per managed asset × Total GB deployed assets. These are derived from public deployment data to avoid k-threshold disclosure issues.

Based on public deployment figures from Zapmap, MCS, DESNZ, and RenewableUK.

Methodology & Data Coverage

How this dashboard was created

Data Collection

Data was collected from energy suppliers, aggregators, and network operators using standardised templates. Each organisation submitted information about their flexible asset portfolios and service participation.

Data Governance

To protect commercial confidentiality, all data undergoes statistical disclosure control. Values are only published when 3 or more contributors exist for that metric. This prevents identification of individual organisations.

k = 3 Minimum contributors per cell

Range Estimates

Where fewer than 3 contributors exist for a dimension, we publish range estimates instead of point values. This statistical disclosure approach (used by ONS and Eurostat) protects individual contributors while still providing useful magnitude information.

5-10 GW = Value falls within this range
50-100 MW = Value falls within this range

Ranges are shown in orange on charts. The bar height represents the range midpoint.
